## 2. 我原来知道什么

### FFT（快速傅里叶变换）
- 将时域信号转换为频域信号
- 告诉我信号包含哪些频率成分
- 用于分析轴承故障特征频率

### 频谱分析
- 观察频率成分的幅值
- 识别故障特征频率（内圈、外圈、滚动体）
- 用于故障诊断

### 轴承故障机理
- 故障产生周期性冲击
- 冲击激发轴承固有频率
- 不同故障类型有不同的特征频率

## 3. 今天新增什么

### FFT的局限性
- **丢失时间信息**：FFT是整段信号的平均，不知道频率成分什么时候出现
- **对瞬态信号不友好**：冲击、瞬变等事件在FFT中被平均掉

### 时间-频率分析的需求
- 轴承故障冲击是**瞬时事件**
- 需要知道**什么时候**发生冲击
- 需要知道冲击激发了**哪些频率**
- 需要看到频率**如何随时间变化**

### STFT（短时傅里叶变换）
- 核心思想：把信号切成小段，对每段做FFT
- 优点：保留了时间信息
- 缺点：时间分辨率和频率分辨率不能同时好
- 窗口大 → 频率分辨率好，但时间分辨率差
- 窗口小 → 时间分辨率好，但频率分辨率差

### CWT（连续小波变换）
- 核心思想：用不同大小的小波去匹配信号
- 优点：多分辨率分析
  - 低频时：用宽的小波，频率分辨率好
  - 高频时：用窄的小波，时间分辨率好
- 像可变焦距的显微镜

### Scale（尺度）
- 小波的大小或拉伸程度
- **小scale**：小波被压缩，适合检测高频成分
- **大scale**：小波被拉伸，适合检测低频成分
- 与频率成反比：小scale → 高频率，大scale → 低频率

### Scalogram（尺度图）
- CWT结果的可视化
- **横轴（x轴）**：时间
- **纵轴（y轴）**：频率（或scale）
- **颜色/幅值**：能量（小波系数的幅值）

### 轴承故障冲击的CWT特征
- **瞬时性**：冲击在特定时间点
- **宽带性**：冲击包含从低频到高频的成分
- **周期性**：故障会周期性重复
- CWT能把这些模式可视化

### 为什么Scalogram可以交给CNN
- Scalogram本质上是一张图像
- CNN擅长图像识别
- 不同故障类型有不同的模式
- CNN自己学习识别这些模式

## 4. FFT与CWT的关系

| 特性 | FFT | CWT |
|------|-----|-----|
| **时间信息** | ❌ 丢失 | ✅ 保留 |
| **频率信息** | ✅ 精确 | ✅ 多分辨率 |
| **适用信号** | 平稳信号 | 非平稳信号 |
| **分辨率** | 固定 | 自适应 |
| **输出** | 1D频谱 | 2D时频图 |
| **类比** | 统计音符 | 乐谱 |

**关键理解**：
- FFT是CWT的特例（固定尺度）
- CWT是FFT的推广（多尺度、多时间）

---

## 5. CWT的核心概念

### 小波（Wavelet）
- 一个小的波形，像一个小波浪
- Morlet小波：高斯包络 × 正弦波
- 与轴承故障冲击的形状相似

### 尺度（Scale）
- 小波的大小
- 小scale → 高频
- 大scale → 低频

### 平移（Translation）
- 小波在时间轴上的位置
- 对应信号的不同时间点

### 小波系数
- 小波与信号匹配的程度
- 幅值大：匹配好，能量强
- 幅值小：匹配差，能量弱

## 6. 最小实验

### 实验设计

**信号1：频率跳变信号**
- 前0.5秒：100Hz正弦波
- 后0.5秒：200Hz正弦波
- 目的：展示FFT丢失时间信息

**信号2：模拟轴承故障冲击**
- 每0.02秒产生一个冲击（50Hz）
- 冲击包含2000Hz高频振荡 + 指数衰减
- 目的：展示CWT对瞬态信号的优势

### 实验代码

`python
# 信号1：频率跳变信号
fs = 1000  # 采样频率 1000 Hz
t = np.linspace(0, 1, fs, endpoint=False)
signal1 = np.zeros_like(t)
signal1[:500] = np.sin(2 * np.pi * 100 * t[:500])  # 前0.5秒：100Hz
signal1[500:] = np.sin(2 * np.pi * 200 * t[500:])  # 后0.5秒：200Hz

# 信号2：模拟轴承故障冲击
fs2 = 10000  # 采样频率 10000 Hz
t2 = np.linspace(0, 0.1, fs2, endpoint=False)
signal2 = np.zeros_like(t2)
for i in range(5):
    idx = int(i * 0.02 * fs2)
    decay = np.exp(-500 * (t2[idx:idx+200] - t2[idx]))
    oscillation = np.sin(2 * np.pi * 2000 * t2[idx:idx+200])
    signal2[idx:idx+200] = decay * oscillation

# FFT分析
fft1 = np.fft.fft(signal1)
freqs1 = np.fft.fftfreq(len(signal1), 1/fs1)
magnitude1 = np.abs(fft1) / len(signal1)

# CWT分析
wavelet = 'morl'  # Morlet小波
scales = np.arange(1, 128)  # 尺度范围
coeffs1, freqs_cwt1 = pywt.cwt(signal1, scales, wavelet, 1/fs1)
scalogram1 = np.abs(coeffs1)
`

## 7. 实验结果

### 信号1：频率跳变信号

**FFT结果**：
- 看到100Hz和200Hz两个峰值
- **但不知道100Hz在前0.5秒，200Hz在后0.5秒**

**CWT Scalogram**：
- 横轴：时间（0-1秒）
- 纵轴：尺度（scale）
- 观察：
  - 前0.5秒：特定尺度范围有能量（对应100Hz）
  - 后0.5秒：不同尺度范围有能量（对应200Hz）
  - **能清楚看到频率跳变的时间点**

### 信号2：模拟轴承故障冲击

**FFT结果**：
- 看到2000Hz峰值
- **但不知道冲击什么时候发生**

**CWT Scalogram**：
- 横轴：时间（0-0.1秒）
- 纵轴：尺度（scale）
- 观察：
  - 每0.02秒出现垂直的高频条纹
  - 这些条纹表示冲击瞬间的高频能量
  - **能清楚看到冲击在什么时候发生**
  - **能看到高频成分如何衰减**

### 关键发现

1. **FFT是平均的**：丢失了时间信息
2. **CWT是局部的**：保留了时间信息
3. **Scalogram是图像**：可以交给CNN识别
