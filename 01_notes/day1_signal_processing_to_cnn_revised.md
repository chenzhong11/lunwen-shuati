## Part A：复习你已有的 FFT 工程知识

### A1. 你已经掌握的核心概念

| 概念 | 你的理解 | 工程意义 |
|------|----------|----------|
| 采样频率 fs | 每秒采样点数 | 决定能分析的最高频率（Nyquist: fmax = fs/2） |
| 采样点数 N | 信号总点数 | 决定频率分辨率 Δf = fs/N |
| 采样时间 T | 信号持续时间 | T = N/fs，与 Δf 成反比：Δf = 1/T |
| 频率分辨率 Δf | 能区分的最小频率差 | Δf = fs/N = 1/T |
| Nyquist 定理 | fs > 2×fmax | 防止混叠 |
| 频谱泄露 | 信号截断导致能量扩散到其他频率 | 有限时间窗口 = 截断 |
| 窗函数 | 汉宁窗等 | 缓解频谱泄露，但会降低频率分辨率 |

### A2. FFT 的本质（用你的语言）

**FFT 回答的问题**：这段信号包含哪些频率成分？每个成分有多少能量？

**FFT 的输出**：
- 横轴：频率（Hz）
- 纵轴：幅值（或能量）
- 含义：整段时间内的平均频率成分

**关键局限**：FFT 不知道频率成分在什么时候出现

## Part B：修正/验证轴承冲击信号模拟

### B1. 检查当前代码的问题

让我先检查 Day 1 原始代码中轴承冲击信号的生成方式：

`python
# 当前 Day 1 代码中的冲击信号生成
fs2 = 10000  # 采样频率 10000 Hz
t2 = np.linspace(0, 0.1, fs2, endpoint=False)  # 0.1秒，1000个点

signal2 = np.zeros_like(t2)
for i in range(5):
    idx = int(i * 0.02 * fs2)  # 每0.02秒一个冲击
    # 问题：idx+200 可能超出数组边界
    decay = np.exp(-500 * (t2[idx:idx+200] - t2[idx]))
    oscillation = np.sin(2 * np.pi * 2000 * t2[idx:idx+200])
    signal2[idx:idx+200] = decay * oscillation
`

### B2. 你的观察是正确的

**问题分析**：
1. 冲击持续时间：200个点 / 10000 Hz = 0.02 秒
2. 冲击间隔：0.02 秒
3. 总时长：0.1 秒

**这意味着**：
- 第1个冲击：0 ~ 0.02 秒
- 第2个冲击：0.02 ~ 0.04 秒
- 第3个冲击：0.04 ~ 0.06 秒
- 第4个冲击：0.06 ~ 0.08 秒
- 第5个冲击：0.08 ~ 0.10 秒

**所以你看到的"0.02~0.1秒基本为0"是不对的**——实际上是5个冲击首尾相接，覆盖了整个0.1秒。

**但这里有一个教学问题**：
- 冲击之间没有间隔，不符合真实轴承故障的物理图像
- 真实轴承故障：冲击是瞬时的，之间有衰减和间隔

### B3. 更合理的教学信号设计

**设计原则**：
1. 冲击应该是瞬时的（持续时间短）
2. 冲击之间有间隔（模拟轴承旋转周期）
3. 冲击包含高频振荡（模拟轴承固有频率激发）
4. 冲击后有衰减（模拟阻尼）

**改进的信号生成代码**：

`python
import numpy as np

# 改进的轴承冲击信号
fs = 10000  # 采样频率 10000 Hz
T = 0.2     # 总时长 0.2秒
t = np.linspace(0, T, int(fs*T), endpoint=False)

# 轴承参数
f_fault = 100      # 故障特征频率 100 Hz（例如外圈故障频率）
f_natural = 2000   # 轴承固有频率 2000 Hz
damping = 500      # 阻尼系数

# 生成冲击序列
signal = np.zeros_like(t)
T_period = 1 / f_fault  # 冲击周期 = 0.01秒

for i in range(int(T * f_fault)):  # 20个冲击
    t_start = i * T_period
    idx_start = int(t_start * fs)
    idx_end = min(idx_start + 200, len(t))  # 冲击持续200个点
    
    if idx_start < len(t):
        # 冲击时间（相对于冲击开始）
        t_impact = t[idx_start:idx_end] - t_start
        
        # 指数衰减 × 高频振荡
        decay = np.exp(-damping * t_impact)
        oscillation = np.sin(2 * np.pi * f_natural * t_impact)
        
        signal[idx_start:idx_end] += decay * oscillation

# 这个信号的特点：
# 1. 每0.01秒出现一次冲击（100 Hz）
# 2. 每次冲击持续约0.02秒
# 3. 冲击包含2000 Hz高频成分
# 4. 冲击后有衰减
# 5. 冲击之间有间隔
`

### B4. 三种信号的区分

| 类型 | 描述 | 用途 |
|------|------|------|
| **教学用人工冲击信号** | 简化的数学模型，用于理解概念 | Day 1 学习 |
| **简化轴承故障模型** | 包含故障特征频率、固有频率、阻尼 | 理解机理 |
| **真实轴承振动信号** | CWRU 等数据集，包含噪声、复杂调制 | 论文复现 |

## Part C：FFT 实验——频谱泄露

### C1. 实验前预测

**实验设置**：
- 采样频率 fs = 1000 Hz
- 采样点数 N = 1000
- 采样时间 T = 1 秒
- 频率分辨率 Δf = fs/N = 1 Hz

**信号**：x(t) = sin(2π×100×t) + sin(2π×200×t)

**问题**：你预计 FFT 会在哪里出现峰值？

**思考**：
1. 100 Hz 和 200 Hz 是否刚好落在 FFT 频率栅格上？
2. Δf = 1 Hz，所以频率栅格是 0, 1, 2, 3, ... Hz
3. 100 Hz 和 200 Hz 都是整数，刚好落在栅格上

**预测**：FFT 应该在 100 Hz 和 200 Hz 处出现两个尖锐的峰值，其他频率幅值应该接近 0。

### C2. 运行实验

`python
import numpy as np
import matplotlib.pyplot as plt

# 参数设置
fs = 1000   # 采样频率
N = 1000    # 采样点数
T = N / fs  # 采样时间 = 1秒
df = fs / N # 频率分辨率 = 1 Hz

# 时间轴
t = np.linspace(0, T, N, endpoint=False)

# 信号：100 Hz + 200 Hz
x = np.sin(2 * np.pi * 100 * t) + np.sin(2 * np.pi * 200 * t)

# FFT
X = np.fft.fft(x)
freqs = np.fft.fftfreq(N, 1/fs)
magnitude = np.abs(X) / N  # 归一化

# 只取正频率
pos_mask = freqs >= 0
freqs_pos = freqs[pos_mask]
magnitude_pos = magnitude[pos_mask]

# 绘图
plt.figure(figsize=(12, 4))
plt.plot(freqs_pos, magnitude_pos)
plt.xlabel('频率 (Hz)')
plt.ylabel('幅值')
plt.title('FFT 频谱')
plt.xlim(0, 300)
plt.grid(True, alpha=0.3)
plt.show()

# 打印关键信息
print(f"频率分辨率 Δf = {df} Hz")
print(f"100 Hz 处幅值 = {magnitude_pos[np.argmin(np.abs(freqs_pos - 100))]:.4f}")
print(f"200 Hz 处幅值 = {magnitude_pos[np.argmin(np.abs(freqs_pos - 200))]:.4f}")
`

### C3. 观察与解释

**观察**：
1. 100 Hz 和 200 Hz 处有明显的峰值
2. 峰值幅值接近 0.5（理论值：sin 函数的幅值是 1，FFT 归一化后是 0.5）
3. **其他频率的幅值非常小，接近 0**

**解释**：
- 因为 100 Hz 和 200 Hz 刚好落在 FFT 频率栅格上（Δf = 1 Hz）
- 没有频谱泄露
- 这是理想情况

### C4. 关键知识结论

**频谱泄露产生的条件**：
1. 信号频率没有刚好落在 FFT 频率栅格上
2. 信号不是采样窗口的整数周期

**数学解释**：
- FFT 假设信号是周期性的，周期 = 采样窗口长度 T
- 如果信号频率 f 满足 f × T = 整数，则信号刚好是整数周期
- 例如：100 Hz × 1 秒 = 100 个周期，刚好是整数
- 如果 f = 100.5 Hz，则 100.5 × 1 = 100.5 个周期，不是整数 → 频谱泄露

**工程类比**：
- FFT 就像用一把尺子（频率栅格）去量信号
- 如果信号刚好是尺子刻度的整数倍，量得很准
- 如果不是，就会"四舍五入"，能量扩散到相邻刻度

## Part D：STFT 实验——为什么需要时间维度

### D1. 从 FFT 到 STFT 的逻辑

**问题**：如果信号是非平稳的（频率随时间变化），FFT 会有什么问题？

**例子**：
- 0 ~ 0.5 秒：100 Hz
- 0.5 ~ 1.0 秒：200 Hz

**FFT 的结果**：
- 看到 100 Hz 和 200 Hz 两个峰值
- 但不知道 100 Hz 在前 0.5 秒，200 Hz 在后 0.5 秒

**STFT 的解决方案**：
- 把长时间信号切成一个个短时间窗
- 每个窗口分别做 FFT
- 随着窗口移动得到一系列频谱

### D2. STFT 的输出

**STFT 的结果**：
- 横轴：时间（窗口中心位置）
- 纵轴：频率
- 颜色：能量/幅值

**这就是时频图的本质**：时间 × 频率 × 能量

### D3. 实验前预测

**信号**：
- 0 ~ 0.5 秒：100 Hz
- 0.5 ~ 1.0 秒：200 Hz

**STFT 设置**：
- 窗口长度：256 个点（0.256 秒）
- 重叠：128 个点（50% 重叠）

**问题**：你预计 STFT 时频图会是什么样子？

**思考**：
1. 在 0 ~ 0.5 秒，应该看到什么？
2. 在 0.5 ~ 1.0 秒，应该看到什么？
3. 在 0.5 秒附近，会发生什么？

### D4. 运行实验

`python
import numpy as np
import matplotlib.pyplot as plt
from scipy import signal

# 参数设置
fs = 1000   # 采样频率
T = 1.0     # 总时长
N = int(fs * T)  # 总点数
t = np.linspace(0, T, N, endpoint=False)

# 信号：0~0.5秒 100Hz，0.5~1秒 200Hz
x = np.zeros_like(t)
x[:N//2] = np.sin(2 * np.pi * 100 * t[:N//2])
x[N//2:] = np.sin(2 * np.pi * 200 * t[N//2:])

# STFT
nperseg = 256  # 窗口长度
noverlap = 128  # 重叠
f, t_stft, Zxx = signal.stft(x, fs, nperseg=nperseg, noverlap=noverlap)

# 绘图
plt.figure(figsize=(12, 8))

# 时域信号
plt.subplot(2, 1, 1)
plt.plot(t, x)
plt.xlabel('时间 (s)')
plt.ylabel('幅值')
plt.title('原始信号')
plt.grid(True, alpha=0.3)

# STFT 时频图
plt.subplot(2, 1, 2)
plt.pcolormesh(t_stft, f, np.abs(Zxx), shading='gouraud')
plt.xlabel('时间 (s)')
plt.ylabel('频率 (Hz)')
plt.title('STFT 时频图')
plt.colorbar(label='能量')
plt.ylim(0, 300)

plt.tight_layout()
plt.show()
`

### D5. 观察与解释

**观察**：
1. 时域信号：前 0.5 秒是 100 Hz，后 0.5 秒是 200 Hz
2. STFT 时频图：
   - 0 ~ 0.5 秒：100 Hz 附近有能量
   - 0.5 ~ 1.0 秒：200 Hz 附近有能量
   - 0.5 秒附近：有过渡区域（因为窗口跨越了跳变点）

**解释**：
- STFT 成功捕捉了频率随时间的变化
- 窗口长度决定了时间分辨率和频率分辨率的权衡
- 窗口越长：频率分辨率越好，但时间分辨率差
- 窗口越短：时间分辨率好，但频率分辨率差

### D6. 关键知识结论

**STFT 的本质**：
- 滑动短时间窗 + 每个窗口做 FFT
- 输出：时间 × 频率 × 能量

**STFT 的局限**：
- 时间分辨率和频率分辨率不能同时好
- 窗口长度固定，对所有频率一视同仁

**为什么需要 CWT**：
- 低频信号需要长窗口（好的频率分辨率）
- 高频信号需要短窗口（好的时间分辨率）
- CWT 自动调整"窗口大小"（通过尺度）

## Part E：CWT 实验——理解 scale / time / coefficient

### E1. CWT 到底在做什么？

**CWT 的核心思想**：用不同大小的"小波"去匹配信号

**类比**：
- 想象你有一把可伸缩的"放大镜"
- 用不同大小的放大镜去看信号
- 放大镜越小：看高频细节
- 放大镜越大：看低频整体

**数学过程**：
1. 选择一个小波（如 Morlet 小波）
2. 对于每个尺度（scale）：
   - 把小波拉伸/压缩到对应大小
   - 在每个时间位置计算小波与信号的匹配程度
   - 匹配程度 = 小波系数
3. 输出：时间 × 尺度 × 小波系数

### E2. "小波"到底是什么？

**小波**：一个小的波形，像一个小波浪

**Morlet 小波**：
- 高斯包络 × 正弦波
- 形状：一个"小鼓包"
- 特点：同时有时间和频率局部性

**类比**：
- 小波就像一个"模板"
- 用这个模板去信号中寻找相似的形状
- 找到的匹配程度就是小波系数

### E3. Scale 与频率的关系

**反比关系**：
- 小 scale → 高频率
- 大 scale → 低频率

**公式**（不需要记，理解即可）：
`
frequency = center_frequency / (scale × dt)
`
其中 center_frequency 是小波的中心频率，dt 是采样间隔

**工程直觉**：
- 小波被压缩（小 scale）→ 快速振荡 → 高频
- 小波被拉伸（大 scale）→ 慢速振荡 → 低频

### E4. 实验前预测

**信号**：
- 0 ~ 0.5 秒：100 Hz
- 0.5 ~ 1.0 秒：200 Hz

**CWT 设置**：
- 小波：Morlet
- 尺度范围：1 ~ 128

**问题**：你预计 CWT 时频图会是什么样子？

**思考**：
1. 在 0 ~ 0.5 秒，应该看到什么尺度/频率有能量？
2. 在 0.5 ~ 1.0 秒，应该看到什么尺度/频率有能量？
3. 与 STFT 相比，有什么不同？

### E5. 运行实验

`python
import numpy as np
import matplotlib.pyplot as plt
import pywt

# 参数设置
fs = 1000   # 采样频率
T = 1.0     # 总时长
N = int(fs * T)  # 总点数
t = np.linspace(0, T, N, endpoint=False)

# 信号：0~0.5秒 100Hz，0.5~1秒 200Hz
x = np.zeros_like(t)
x[:N//2] = np.sin(2 * np.pi * 100 * t[:N//2])
x[N//2:] = np.sin(2 * np.pi * 200 * t[N//2:])

# CWT
wavelet = 'morl'  # Morlet 小波
scales = np.arange(1, 128)  # 尺度范围

coefficients, frequencies = pywt.cwt(x, scales, wavelet, 1/fs)
scalogram = np.abs(coefficients)

# 绘图
plt.figure(figsize=(12, 8))

# 时域信号
plt.subplot(2, 1, 1)
plt.plot(t, x)
plt.xlabel('时间 (s)')
plt.ylabel('幅值')
plt.title('原始信号')
plt.grid(True, alpha=0.3)

# CWT 时频图
plt.subplot(2, 1, 2)
plt.imshow(scalogram, aspect='auto', extent=[0, T, scales[-1], scales[0]], 
           cmap='jet', interpolation='bilinear')
plt.xlabel('时间 (s)')
plt.ylabel('尺度 (scale)')
plt.title('CWT Scalogram')
plt.colorbar(label='能量')

plt.tight_layout()
plt.show()

# 打印尺度与频率的对应关系
print("尺度与频率对应关系（部分）：")
for scale in [10, 20, 50, 100]:
    freq = pywt.scale2frequency(wavelet, scale, 1/fs)
    print(f"  scale={scale} → 频率={freq:.1f} Hz")
`

### E6. 观察与解释

**观察**：
1. CWT 时频图：
   - 0 ~ 0.5 秒：某个尺度范围有能量（对应 100 Hz）
   - 0.5 ~ 1.0 秒：不同尺度范围有能量（对应 200 Hz）
   - 0.5 秒附近：有过渡区域

2. 尺度与频率的对应：
   - scale=10 → 频率≈47.7 Hz
   - scale=20 → 频率≈23.9 Hz
   - scale=50 → 频率≈9.5 Hz
   - scale=100 → 频率≈4.8 Hz

**解释**：
- CWT 成功捕捉了频率随时间的变化
- 小 scale 对应高频，大 scale 对应低频
- CWT 的优势：多分辨率分析

### E7. 关键知识结论

**CWT 的本质**：
- 用不同尺度的小波去匹配信号
- 输出：时间 × 尺度 × 小波系数

**Scale 的含义**：
- 小波的大小/拉伸程度
- 小 scale → 高频，大 scale → 低频

**CWT vs STFT**：
- STFT：固定窗口，所有频率同等对待
- CWT：自适应窗口，低频用长窗口，高频用短窗口

**工程意义**：
- 高能量区域 = 信号中存在该尺度/频率的成分
- 低能量区域 = 信号中没有该尺度/频率的成分

## Part G：FFT vs STFT vs CWT

### G1. 三种方法的对比

| 特性 | FFT | STFT | CWT |
|------|-----|------|-----|
| **时间信息** | ❌ 丢失 | ✅ 保留 | ✅ 保留 |
| **频率信息** | ✅ 精确 | ✅ 固定分辨率 | ✅ 多分辨率 |
| **适用信号** | 平稳信号 | 非平稳信号 | 非平稳信号 |
| **分辨率** | N/A | 固定 | 自适应 |
| **输出维度** | 1D（频率） | 2D（时间×频率） | 2D（时间×尺度） |
| **类比** | 统计音符 | 固定焦距相机 | 可变焦距显微镜 |

### G2. 什么时候用什么？

**FFT**：
- 信号是平稳的（频率不随时间变化）
- 只需要知道"包含哪些频率"
- 例如：稳态运行的电机振动

**STFT**：
- 信号是非平稳的
- 需要知道"频率随时间的变化"
- 对所有频率同等对待
- 例如：语音信号、音乐信号

**CWT**：
- 信号是非平稳的
- 需要多分辨率分析
- 低频需要好的频率分辨率，高频需要好的时间分辨率
- 例如：轴承故障冲击、地震信号

### G3. 对于轴承故障诊断

**为什么 CWT 更适合**：
1. 轴承故障冲击是瞬态事件
2. 冲击包含从低频到高频的成分
3. 低频成分（故障特征频率）需要好的频率分辨率
4. 高频成分（固有频率激发）需要好的时间分辨率
5. CWT 自动调整分辨率，适合这种信号

## Part H：CWT 与轴承故障机理

### H1. 轴承故障的物理过程

`
轴承故障（局部缺陷）
    ↓
滚动体经过缺陷位置
    ↓
产生机械冲击
    ↓
冲击激发轴承固有频率（高频）
    ↓
振动信号中出现瞬态脉冲
    ↓
脉冲包含从低频到高频的成分
`

### H2. FFT 能看到什么？

**FFT 可以看到**：
- 故障特征频率（BPFO, BPFI, BSF）
- 固有频率
- 但这些频率是"平均"的结果

**FFT 看不到**：
- 冲击在什么时候发生
- 冲击的瞬态特性
- 高频成分如何衰减

### H3. CWT 为什么特别适合？

**CWT 能够捕捉**：
1. **时间位置**：冲击什么时候发生
2. **频率分布**：冲击激发了哪些频率
3. **衰减模式**：高频成分如何随时间衰减

**CWT 图上的特征**：
- 冲击时间点：出现垂直的高能量条纹
- 高频成分：在小 scale（图上方）有能量
- 低频成分：在大 scale（图下方）有能量
- 衰减：能量从高频向低频扩散

### H4. 为什么"什么时候出现冲击"很重要？

**诊断价值**：
- 冲击的时间间隔 → 故障特征频率 → 故障类型
- 冲击的频率成分 → 轴承固有频率 → 轴承状态
- 冲击的衰减模式 → 阻尼特性 → 轴承健康状态

**类比**：
- 医生听心跳：不仅听"心跳是什么频率"，还听"心跳什么时候出现"
- 工程师看振动：不仅看"振动包含什么频率"，还看"冲击什么时候发生"

### H5. 迁移到液压系统

**液压系统中的类似现象**：

| 现象 | 物理过程 | CWT 能看到什么 |
|------|----------|----------------|
| **液压泵冲击** | 柱塞/叶片经过排油口 | 冲击时间、频率成分 |
| **阀切换** | 阀芯快速移动 | 切换时间、压力瞬态 |
| **泄漏** | 流体通过小缝隙 | 持续的高频噪声 |
| **压力脉动** | 泵的固有特性 | 脉动频率、幅值变化 |
| **气穴/气蚀** | 气泡破裂 | 瞬态高频冲击 |

**共同点**：
- 都是瞬态或非平稳信号
- 都需要同时知道时间和频率信息
- CWT 都是合适的分析工具

## Part I：从 CWT 图过渡到 CNN

### I1. 为什么作者不直接把原始振动信号输入 CNN？

**原始振动信号的问题**：
1. 是一维时间序列
2. 包含大量冗余信息
3. 故障特征被噪声和复杂调制掩盖
4. CNN 不擅长直接从原始信号学习

**CWT 的优势**：
1. 把一维信号转换为二维图像
2. 突出了时频特征
3. 把故障模式可视化
4. CNN 擅长处理图像

### I2. 为什么把 CWT 结果画成二维图？

**CWT 的输出**：
- 时间 × 尺度 → 小波系数（二维矩阵）

**转换为图像**：
- 横轴：时间
- 纵轴：尺度（或频率）
- 颜色：小波系数的幅值

**意义**：
- 把抽象的数学结果变成可视化的图像
- 人眼可以识别图像中的模式
- CNN 也可以识别图像中的模式

### I3. 为什么二维 CNN 能处理这个图？

**CNN 的本质**：
- 卷积神经网络，专门设计用于处理图像
- 通过卷积核提取图像中的局部特征
- 通过多层网络提取从低级到高级的特征

**CNN 处理 CWT 图**：
- 把 CWT 图像当作一张普通的图像
- 卷积核在图像上滑动，提取局部模式
- 例如：冲击的形状、能量分布模式等

### I4. CNN 到底在图上学习什么？

**CNN 学习的是**：
- 不同故障类型在 CWT 图上有什么不同的模式
- 例如：内圈故障、外圈故障、滚动体故障的 CWT 图有什么不同

**CNN 不知道的**：
- 什么是轴承故障机理
- 什么是故障特征频率
- 什么是物理冲击

**CNN 只是**：
- 从训练数据中学习"哪些二维模式和标签经常共同出现"
- 是统计映射，不是物理理解

### I5. 关键提醒

**CNN 的本质**：
- 学习：CWT 图像 → 故障标签 的映射
- 不理解：物理机理
- 优势：自动学习特征，不需要人工设计

**为什么需要"机理 + 数据驱动"**：
- 纯数据驱动：CNN 可能达到很高准确率，但不知道为什么
- 纯机理驱动：需要专家知识，可能不够准确
- 结合两者：既准确又可解释

## Part J：Day 1 最终知识链

### J1. 完整的 Mechanism-to-Algorithm Bridge

`
机械故障（轴承缺陷）
    ↓
局部缺陷 + 滚动体经过
    ↓
产生机械冲击（瞬态脉冲）
    ↓
冲击激发固有频率（高频）
    ↓
振动信号出现瞬态脉冲
    ↓
FFT：能看到频率成分，但丢失时间信息
    ↓
STFT：能保留时间信息，但分辨率固定
    ↓
CWT：多分辨率分析，适合瞬态信号
    ↓
CWT 图：时间 × 尺度 × 能量
    ↓
CNN：从 CWT 图像中学习故障模式
    ↓
输出：故障分类（正常/内圈/外圈/滚动体）
`

### J2. Day 1 必须真正掌握的知识

1. **FFT 本质**：回答"这段信号包含哪些频率成分"，但丢失时间信息
2. **频谱泄露**：信号频率不在 FFT 频率栅格上时，能量扩散到相邻频率
3. **频率分辨率**：Δf = fs/N = 1/T，由采样时间和采样频率决定
4. **STFT 原理**：滑动短时间窗 + 每个窗口做 FFT，输出时间×频率×能量
5. **STFT 局限**：时间分辨率和频率分辨率不能同时好
6. **CWT 原理**：用不同尺度的小波匹配信号，输出时间×尺度×小波系数
7. **Scale 与频率**：小 scale → 高频，大 scale → 低频，成反比关系
8. **CWT 优势**：多分辨率分析，低频用长窗口，高频用短窗口
9. **轴承故障冲击**：瞬态事件，包含从低频到高频的成分
10. **CWT 适合轴承故障**：能同时捕捉时间位置、频率分布、衰减模式
11. **CWT 图阅读**：横轴时间，纵轴尺度，颜色能量
12. **CNN 处理 CWT 图**：把 CWT 图像当作普通图像，学习故障模式
13. **CNN 的本质**：学习图像→标签的统计映射，不理解物理机理
14. **机理+数据驱动**：结合物理理解和数据驱动，既准确又可解释
15. **液压系统迁移**：冲击、脉动、泄漏、阀切换等瞬态现象都可以用 CWT 分析

## 我的 Day 1 疑问与解答

### 疑问 1：轴承冲击信号模拟是否合理？

**问题**：代码中"前面有冲击、后面大量为0"的设计是否有问题？

**解答**：
- 原始代码实际上生成了 5 个首尾相接的冲击，覆盖整个 0.1 秒
- 但这种设计不符合真实轴承故障的物理图像
- 真实轴承故障：冲击是瞬时的，之间有间隔和衰减
- 改进方案：设计更合理的冲击序列，包含间隔和衰减

### 疑问 2：为什么 FFT 图中除了 100 Hz 和 200 Hz 还有其他频率？

**解答**：
- 如果信号频率刚好落在 FFT 频率栅格上，理论上只有两个峰值
- 实际中可能的原因：
  1. 信号频率没有刚好落在栅格上（频谱泄露）
  2. 有限时间截断（相当于加了矩形窗）
  3. FFT 频率分辨率不足
  4. 有噪声
- 在我们的实验中，100 Hz 和 200 Hz 刚好落在栅格上（Δf = 1 Hz），所以其他频率幅值很小

### 疑问 3：FFT "首尾相接"的理解是否正确？

**解答**：
- "首尾相接"是工程上的形象化理解
- 更严谨的说法：DFT 的周期延拓假设
- DFT 假设信号是周期性的，周期 = 采样窗口长度
- 如果信号刚好是整数周期，首尾相接是连续的
- 如果不是，首尾不连续，导致频谱泄露

### 疑问 4：为什么需要从 FFT 过渡到 STFT？

**解答**：
- FFT 适用于平稳信号（频率不随时间变化）
- 对于非平稳信号（如频率跳变），FFT 丢失时间信息
- STFT 通过滑动短时间窗，保留了时间信息
- STFT 输出：时间 × 频率 × 能量

### 疑问 5：CWT 图看不懂怎么办？

**解答**：
- 横轴：时间
- 纵轴：尺度（与频率成反比）
- 颜色：能量（小波系数幅值）
- 高能量区域 = 信号中存在该尺度/频率的成分
- 通过读图练习，逐步建立直觉

### 疑问 6：为什么 CWT 适合轴承故障诊断？

**解答**：
- 轴承故障冲击是瞬态事件
- 冲击包含从低频到高频的成分
- CWT 能同时捕捉时间位置、频率分布、衰减模式
- CWT 图上的冲击特征：垂直的高能量条纹

### 疑问 7：CNN 到底在学什么？

**解答**：
- CNN 学习：CWT 图像 → 故障标签 的映射
- CNN 不知道：物理机理、故障特征频率、物理冲击
- CNN 只是统计：哪些二维模式和标签经常共同出现
- 这就是"数据驱动"的本质
