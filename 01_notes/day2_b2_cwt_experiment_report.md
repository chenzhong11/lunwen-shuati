## 三、CWT输出shape验证

### 实验结果

| Scale范围 | scales数量 | coefficients.shape | frequencies.shape | 频率范围 |
|-----------|-----------|-------------------|------------------|----------|
| 1~32 | 32 | (32, 1000) | (32,) | 25.39~812.50 Hz |
| 1~64 | 64 | (64, 1000) | (64,) | 12.70~812.50 Hz |
| 1~128 | 128 | (128, 1000) | (128,) | 6.35~812.50 Hz |

### 维度含义验证

```
coefficients.shape = (n_scales, n_time_points)
                     ↓           ↓
                 第一维(axis=0)  第二维(axis=1)
                 Scale维度       Time维度
```

**关键发现**：
- CWT输出是一个二维矩阵
- 第一维：scale维度（不同尺度的小波系数）
- 第二维：time维度（每个时间点的系数）
- 时间点数量 = 原始信号长度

## 四、scale-frequency关系

### Scale-Frequency对应表

| Scale | Frequency (Hz) |
|-------|----------------|
| 1 | 812.50 |
| 2 | 406.25 |
| 5 | 162.50 |
| 10 | 81.25 |
| 15 | 54.17 |
| 20 | 40.62 |
| 30 | 27.08 |
| 50 | 16.25 |
| 75 | 10.83 |
| 100 | 8.12 |
| 128 | 6.35 |

### 关系分析

1. **scale增大时frequency如何变化**：
   - scale=1: 812.50 Hz
   - scale=64: 12.70 Hz
   - scale=128: 6.35 Hz
   - **结论**: scale增大，frequency减小（反比关系）

2. **是否严格线性**：
   - 相邻scale的频率差值：[-406.25, -135.42, -67.71, -40.63, -27.08, ...]
   - 差值不是常数
   - **结论**: 不是严格线性，是反比关系 f ∝ 1/scale

3. **为什么scale不是frequency**：
   - Scale是小波的"拉伸程度"
   - Frequency是物理频率
   - 两者通过公式转换：f = center_frequency / (scale × dt)

4. **100 Hz和200 Hz对应的scale**：
   - 100 Hz附近：scale=8，实际频率=101.56 Hz
   - 200 Hz附近：scale=4，实际频率=203.12 Hz

## 五、CWT图逐项解释

### 图表文件
- `day2_cwt_matrix_visualization.png`

### 四个子图说明

1. **原始时域信号**
   - 横轴：时间 (0~1秒)
   - 纵轴：幅值
   - 观察：0.5秒处有频率跳变（100Hz→200Hz）

2. **CWT Coefficient Magnitude矩阵**
   - 横轴：时间点（0~1000）
   - 纵轴：Scale（1~128）
   - 颜色：系数幅值（蓝→红）
   - 观察：0.5秒处有明显的能量分布变化

3. **Scalogram (Scale为纵轴)**
   - 横轴：时间 (秒)
   - 纵轴：Scale
   - 颜色：能量
   - 观察：小scale（高频）在0~0.5s有能量，大scale（低频）在0.5~1.0s有能量

4. **Scalogram (Frequency为纵轴)**
   - 横轴：时间 (秒)
   - 纵轴：频率 (Hz)
   - 颜色：能量
   - 观察：0~0.5s在200Hz附近有能量，0.5~1.0s在100Hz附近有能量

### 关键观察

**矩阵结构**：
- 每一行：对应一个scale，包含该scale在所有时间点的小波系数
- 每一列：对应一个时间点，包含该时间点在所有scale的小波系数
- 系数值：表示信号与该scale小波在该时间点的匹配程度

## 六、96×96尺寸转换实验

### 实验设置

| 参数 | 原始 | 目标 |
|------|------|------|
| Scale维度 | 128 | 96 |
| Time维度 | 1000 | 96 |

### 转换过程

```
原始CWT矩阵: (128, 1000)
    ↓
计算缩放因子:
  - Scale维度: 96/128 = 0.75
  - Time维度: 96/1000 = 0.096
    ↓
双三次插值 (order=3)
    ↓
输出: (96, 96)
```

### 图表文件
- `day2_resize_comparison.png`

### Resize改变了什么

1. **Scale维度: 128 → 96**
   - 丢失了32个scale的信息
   - 通过插值"猜测"中间值
   - 低频分辨率降低

2. **Time维度: 1000 → 96**
   - 丢失了904个时间点的信息
   - 通过插值"猜测"中间值
   - 时间分辨率大幅降低（约10倍）

3. **视觉影响**
   - 图像变得更模糊
   - 细节信息丢失
   - 但整体模式保留

### 关键结论

**96×96不是CWT的天然输出**：
- CWT天然输出是 (n_scales, n_time_points)
- 时间点数量 = 原始信号长度
- 必须通过resize才能得到96×96图像
